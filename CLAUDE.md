## What this addon is now (19 Sep 2026)

The second addon of this name. The first was 5,000 lines of shaman Chain Heal brain, ranked out of the combat log; it is tagged `tbc-final` and is not coming back. Nothing in this folder is for TBC any more, and no file here may read a number the client calls secret.

## Layout (BiSHealing only)

- `BiSHealing.toc`: the load order, and the only place the version lives (`## Version`, currently `0.1.0`). It claims `## Interface: 20506, 16001` — both censuses, so the fence judges both. `## SavedVariables: BiSHealingDB`, `## OptionalDeps: BiSTheme, Blizzard_AuraContainer` (the aura containers belong to Blizzard's own addon; without the dep line, building one is a protected action and the client pops a dialog at every layout).
- `Lockdown.lua`: loads first and answers the questions that decide everything else — `NS.SECRET` (does this client hide its numbers), `NS.Blind()` (are we inside the lockdown, where auras and cooldowns go secret too), and since 19 Sep **`NS.Secret(v)` / `NS.Plain(v)`**, which wrap the client's own `issecretvalue`. Use those for any value that goes into an `if` or indexes a table: a secret boolean refuses the test itself, and a secret string refuses to be a table key. Feature-detected through `C_Secrets`, never a build number.
- `Core.lua`: the saved variables (`NS.DB`, `NS.DBVER` 1, with the one-time migration out of the old addon's table), `NS.Print`, `NS.VERSION` read from the TOC, **`NS.DO`** and the slash command. `NS.DO` is the table of everything the addon can be asked to do; the slash command, the minimap menu and the options window all go through it, so the three doors cannot drift. `/bish`, `/bisheals` and `/bishf` all reach it — the last is an alias kept because it is what has been typed here for a week.
- `Grid.lua`: the cells. `FG.Roster` (group order, never health order), `Make`, `Bind`, `Layout`, `Paint`, `Start`. **The rule this file exists to keep: the value the client gives is handed on untouched** — into `SetValue`, into a font string, never into arithmetic or a comparison. That now covers `f.incoming`, the heals-on-their-way bar, which is anchored to the health bar's *texture* so it starts where the fill ends. It holds no spell names; "can I reach them" asks `NS.FM.RangeSpell()` (whatever is on the left button) through `C_Spell.IsSpellInRange` — the bare global does not exist on 1.60.1.
- `Auras.lua`: markers the client draws for auras we may not read (`AuraContainer` + `CustomAuraContainerTemplate`). The dispel slot asks for `HARMFUL|RAID_PLAYER_DISPELLABLE` and narrows it with **nothing** — the client's own answer covers whoever is playing. `FA.WATCH` is an empty switch. `FA.Debug` marks every debuff, to tell "the markers do not draw" apart from "you cannot cure that".
- `Mouse.lua` / `MouseUI.lua`: every click meaning in one place. Buttons 1-5 are secure attributes on the cells; the wheel is a *binding*, so it goes through a hidden secure button holding `/cast [@mouseover]`. Both are refused in combat and queued. Binds keep their **rank** (`Name(Rank 3)`), and the icon is looked up without it. `FM.CLASS_DEFAULTS` is the only class-shaped thing in the addon.
- `Between.lua`: what can be learned when the lockdown lifts (`PLAYER_REGEN_ENABLED`). `/bish scan` asks it now; it owns no slash command of its own.
- `UI/options.lua`: eight rows, all of them `NS.DO` calls, on BiSTheme's shared kit. `NS.UI.Rows()` is what a suite reads back.
- `UI/minimap.lua`: the rows behind the minimap button (BiSTheme's `Minimap.lua`).
- `Libs/`: BiSTheme only (`Console.lua`, `Options.lua`, `Minimap.lua`) — copies, never edited here. See the libs rules in `../_bisdev/CLAUDE.md`.
- `dev/tests.lua`: the suite, 132 checks. It **reads the TOC** and loads every file the client would, in order — a hand-written list goes stale, and this one lost 5,000 lines in a day. The client it mocks is the measured one: secret numbers that error on arithmetic, comparison and `tostring`; `UnitInRange` a secret boolean; aura containers; `GetCursorInfo` in its four-value Forever shape. It covers the migration in detail, because getting that wrong loses somebody's binds silently.
- `dev/theme.lua`: asserts the embedded BiSTheme bytes match canon.
- `.github/workflows/check.yml`: calls the reusable CI workflow in `bisdev`.
